# Ejercicio 4: Carrera

Crea un programa en Kotlin con Android Studio para simular una carrera de atletas.

1. Cada atleta deberá recorrer 100 metros, y en cada avance se generará una cantidad aleatoria de metros.
2. En cada iteración, se identificará a cada atleta y se indicará cuántos metros ha recorrido.
3. Cuando un atleta llegue a la meta, lo avisará por consola y terminará su ejecución.
4. El programa principal avisará cuando termine la carrera.
